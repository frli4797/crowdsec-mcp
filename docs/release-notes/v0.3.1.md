# Release Notes: v0.3.1

## Summary

`v0.3.1` improves CI cache behavior for faster, cleaner validation and image builds.

## Added

- None.

## Changed

- Upgraded direct GitHub Actions cache usage to `actions/cache@v5` for Node.js 24 compatibility.
- Keyed cached Python virtualenvs by the resolved Python patch version.
- Split Docker runtime/build dependency installation from source installation so code-only image builds can reuse expensive dependency layers across architectures.

## Fixed

- Reduced repeated dependency installation during multi-architecture Docker builds when only application source files change.

## Security And Safety

- CrowdSec-only MCP boundary is unchanged.
- Existing IP write actions remain single-IP, prepare-only, and audited.

## Upgrade Notes

- Update deployments to use `ghcr.io/frli4797/crowdsec-ops-mcp:0.3.1` after the image is published.
- Existing MCP configuration variables remain compatible.

## Validation

- `python3 -m compileall src tests`
- `.venv/bin/python scripts/check_version.py v0.3.1`
- `.venv/bin/python -m pytest`
- `.venv/bin/python -m build --no-isolation`
- Docker image build
