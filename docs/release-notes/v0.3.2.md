# Release Notes: v0.3.2

## Summary

`v0.3.2` removes the unsupported scenario simulation enable/disable MCP tools after local testing confirmed that standard CrowdSec LAPI does not expose scenario simulation management.

## Added

- None.

## Changed

- Updated documentation and agent guidance to remove scenario simulation write prompts and API-write safeguards that no longer apply.

## Fixed

- Removed `enable_scenario_simulation(...)` and `disable_scenario_simulation(...)` from the MCP tool surface.
- Removed scenario simulation API-write configuration and tests for the unsupported LAPI route.

## Security And Safety

- CrowdSec-only MCP boundary is unchanged.
- IP write tools remain single-IP, prepare-only, and audited.
- No MCP-executed CrowdSec mutations are introduced.
- Scenario simulation remains an operator-managed CrowdSec deployment action outside this MCP runtime.

## Upgrade Notes

- Deployments do not need `WRITE_OPERATIONS_ENABLED` or `CROWDSEC_LAPI_SIMULATION_PATH_TEMPLATE`; those variables are no longer used.
- Use operator-reviewed CrowdSec deployment procedures for scenario simulation management.

## Validation

- `uv run --extra dev pytest`
